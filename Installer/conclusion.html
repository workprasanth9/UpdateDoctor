Thank you for installing UpdateDoctor __VERSION__!

Open UpdateDoctor from your Applications folder. It lives in the menu bar as a colored dot: green is healthy, yellow is at risk, red is blocked. There is no Dock icon.

The updatedoctor command is installed in /usr/local/bin. Open Terminal and run sudo updatedoctor doctor to see why this Mac did or did not update.

UpdateDoctor only reads. It never installs, downloads or changes anything.

If UpdateDoctor saves you a support ticket, please star it on GitHub and share it with a Mac admin friend. It really helps, and it keeps the updates coming.
